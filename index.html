    Quick Start
    From zero to running in 5 commands
    Terminal
    $ degen init
      Project name: sales_pipeline
      Pattern: Analytics
      Tools: Airflow · dbt · Postgres · Grafana
      ✓ Generated sales_pipeline/

    $ degen install
      ✓ Dependencies installed

    $ degen docker-up
      ✓ Postgres · pgAdmin · Grafana · Airflow

    $ degen run
      ✓ Pipeline executed

    $ degen ui
      Airflow UI   →  http://localhost:8080
      pgAdmin     →  http://localhost:5050
      Grafana     →  http://localhost:3001
    Architecture Patterns
    Choose your stack

    Three production-proven patterns. Each one generates a fully working project.

    Pattern 01

    Batch ETL

    Extract raw data, transform with dbt, persist in DuckDB or Postgres. Explore results in Jupyter.

    Python dbt DuckDB Postgres
    Pattern 02

    Analytics

    Orchestrate scheduled pipelines with Prefect or Airflow. Visualize with Grafana or Metabase.

    Airflow dbt Postgres Grafana
    Pattern 03

    Streaming

    Real-time event processing with Kafka and PySpark Structured Streaming.

    Kafka PySpark ClickHouse
